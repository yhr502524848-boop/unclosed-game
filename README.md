# 尚未注销

一款以数字遗产、记忆篡改与人物关系为核心的中文网页调查游戏。

玩家作为余声平台的复核员，从数字人格留下的一句“我还活着”开始，通过聊天、录音、工作档案和个人日记还原许知遥的经历。

## 在线体验

[在线游玩](https://yhr502524848-boop.github.io/unclosed-game/)

加上 `?play=任意新名称` 可使用独立存档重新体验，不覆盖原进度。

## 文件

- `index.html`：可直接运行的单文件游戏。
- `data.js`：剧情、档案与人物数据。
- `model.js`：调查进度、检索、解锁和存档逻辑。
- `ui.js`：页面交互与渲染逻辑。

游戏进度保存在浏览器本地存储中。

## 本地修改与检查

修改剧情及逻辑后运行 `node test.cjs`，再运行 `node build.cjs` 将三个 JavaScript 源文件写入单文件网页。页面结构与样式保存在 `index.html` 中。`fixtures/` 用于验证旧存档迁移。

## 2026-10-19 调查体验更新

- 检索保留输入与检索词；未命中显示独立空结果；支持中文日期、补零和常见分隔符。
- 明确引用可直接打开；已知但受限的材料显示等待或登录原因，正文仍受阶段及权限限制。
- 当前调查问题与三级可展开提示；第三阶段以直接证据为准，不再强制重复读引介文件。
- 第 1、3、5 阶段由玩家完成证据核对后记档；支持已读材料对照、收藏、最近阅读及按阶段折叠。
- 记录成功和未命中的提问，最新在前；分别保留查档与询问输入。
- 生日日记摘页提前随相册出现；私人备份补充密码沿用依据。
- 后段补充开场留言的来源凭据、批次与收付款对照；结尾改为选择提交顺序。
- 兼容既有已完成的阶段和结局；重新开局可体验新增核对环节。
